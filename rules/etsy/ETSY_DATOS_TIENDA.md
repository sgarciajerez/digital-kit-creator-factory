# Datos preparados para MaquetasExcel

La tienda se ha orientado a recursos digitales prácticos: plantillas Excel, e-books y herramientas digitales. La estructura toma como referencia la claridad de categorías, el anuncio breve, la explicación del proceso de descarga y las preguntas frecuentes de tiendas consolidadas de este sector, sin copiar textos de terceros.

## Texto ya aplicado mediante la API de Etsy

- **Título:** Plantillas Excel, e-books y herramientas digitales
- **Anuncio:** Bienvenido a MaquetasExcel. Creamos plantillas Excel, e-books y herramientas digitales sencillas para organizar tus finanzas, proyectos y trabajo. Descargas inmediatas, instrucciones claras y recursos prácticos para empezar hoy.
- **Mensaje tras la compra:** Gracias por confiar en MaquetasExcel. Si necesitas ayuda con tu descarga o con el uso del archivo, escríbeme desde Etsy y te ayudaré lo antes posible.
- **Mensaje para productos digitales:** Tu descarga digital estará disponible en tu cuenta de Etsy después de confirmar el pago. No se envía ningún producto físico. Si el archivo no aparece o tienes algún problema, escríbeme desde Etsy.
- **Política adicional:** Todos los productos de esta tienda son descargas digitales; no se envían artículos físicos. Antes de comprar, revisa la descripción, el formato incluido y los requisitos de software. Los archivos están pensados para uso personal o profesional del comprador y no pueden redistribuirse ni revenderse como producto independiente. Debido a la naturaleza digital de los productos, las devoluciones y cancelaciones se gestionan conforme a las políticas aplicables de Etsy y la legislación correspondiente. Si tienes un problema con la descarga, contacta conmigo desde Etsy.

MaquetasExcel nace para convertir tareas repetitivas en procesos más claros. Diseñamos plantillas Excel, e-books y herramientas digitales prácticas para organizar presupuestos, proyectos, pequeños negocios y objetivos personales. ## Preguntas frecuentes preparadas

### ¿Qué recibiré después de comprar?

Recibirás los archivos digitales indicados en la descripción de cada producto. No se envía ningún artículo físico.

### ¿Cómo descargo mi compra?

Etsy habilita la descarga cuando confirma el pago. Puedes acceder desde el navegador, en tu historial de compras.

### ¿Necesito Microsoft Excel?

Cada anuncio especifica el formato incluido y los requisitos. Comprueba esa información antes de comprar.

### ¿Puedo pedir ayuda si algo no funciona?

Sí. Escríbeme desde Etsy indicando el producto y el problema, sin compartir datos sensibles, y revisaré el caso.

## Pendiente de completar manualmente en Etsy

La API de Etsy permite actualizar el título, anuncio y mensajes, pero no todos los campos del editor visual de la tienda. En **Shop Manager** hay que revisar:

1. **Shop home editor / Editar tienda:** subir logo, banner y completar “About”.
2. **Listings > Manage sections:** comprobar las tres secciones y añadir productos nuevos cuando estén creados.
3. **Shop policies:** revisar pagos, cancelaciones, devoluciones y descargas digitales.
4. **Privacy policy:** introducir la identidad legal y datos de contacto reales del titular. No se han inventado esos datos.
5. **FAQ:** añadir las cuatro preguntas anteriores.

No se debe publicar una política de privacidad con datos ficticios. Para completarla hacen falta el nombre legal del titular, país/domicilio aplicable y correo de contacto de privacidad.
